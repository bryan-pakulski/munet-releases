# ONNX operator coverage

Generated by `python tools/op_coverage.py` from the ONNX operator schemas (default domain, operators live in
opsets 13-21) and checked by `tests/test_onnx_ops.py`. Forward = imported by `munet.interop.from_onnx` (static
shapes); every imported op runs on both the CPU reference and Vulkan. Backward describes the gradient of the
lowered graph ("zero" for piecewise-constant ops). Integer tensors are carried as exact integer-valued floats.
Operators whose output shape depends on data (NonZero/Unique on runtime inputs) and string/bytes operators run at
import from constant inputs (MuNet tensors are numeric and static). NonMaxSuppression imports with a static bound
(max_output_boxes_per_class rows per batch and class) when its result is a model output: padding rows are trimmed
on the host and the call returns int64 [num_selected, 3]. Sequences and optionals are resolved at import; If selects
a branch (constant condition) or both branches with Where (runtime condition, equal shapes); Loop/Scan/SequenceMap
and RNN/GRU/LSTM are unrolled over static lengths (Loop conditions must be known at import). Random operators
draw new samples every call (a per-program counter).
